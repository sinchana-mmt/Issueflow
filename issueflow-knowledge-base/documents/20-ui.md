The visual direction is minimalist dark SaaS. The default appearance is a dark theme. It should feel like a modern professional productivity application. Styling is Tailwind CSS. Components are shadcn/ui. Icons are Lucide. Typography is Inter.

Visual characteristics: deep charcoal background; a slightly lighter sidebar; dark gray surfaces; subtle borders; indigo primary accent; green success; amber warning; red critical; 8 to 12 px border radii; minimal icons; consistent spacing; a clear type hierarchy; subtle hover and focus states.

The design avoids excessive gradients, bright colors everywhere, too many dashboard cards, heavy borders, unnecessary animations, cluttered navigation, and overloaded issue forms.

Sidebar order: Overview, All Issues, My Issues, Board, Projects, Tags, Team, Settings.

Top navigation: current page title, search, notifications, user profile, and a primary action such as Create Issue.

P0 screens, required for the first usable MVP: Login, Overview dashboard, All Issues, Create Issue, Issue Details, Projects, Project Details, Kanban Board, My Issues, Team Management.

P1 screens, which complete the planned MVP experience: Notifications, Settings, Saved Filters.

The experience is desktop-first. It supports tablet layouts and mobile browsing with basic issue operations. The sidebar collapses on smaller screens. Tables adapt to smaller widths. Issue detail panels stack vertically on mobile. Kanban scrolls horizontally.

The PRD does not require a light theme, localization, or a keyboard alternative for drag-and-drop. Settings contents are not listed.
